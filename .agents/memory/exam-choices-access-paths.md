---
name: Exam choices across access paths
description: Keep answer-choice text visible in every student exam flow regardless of how lesson access was granted.
---

Students who open lessons with a standard code must see the same answer-choice text as students using Promo Code access; the correct-answer key must remain hidden.

Past exam review must preserve the question, all four choice texts, the student's selection, and the correct selection.

**Why:** On 2026-10-12, the user reported that standard-code students saw only answer letters while Promo Code students saw full choices. The difference came from separate student exam interfaces.

**How to apply:** When changing quiz data or exam UI, check every student entry path and preserve server-side removal of correct answers.
