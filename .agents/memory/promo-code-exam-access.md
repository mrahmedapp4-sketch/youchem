---
name: Promo Code exam access
description: Product rule for how student Promo Code access and lesson exams interact.
---

Students who receive lesson access through a Promo Code should still be able to take the lesson exam. Passing or failing the exam must not determine whether Promo Code lesson access remains open; scores and corrections should remain available separately.

**Why:** The user specifically asked that Promo Code access not suppress lesson exams or make a failed attempt revoke lesson access.

**How to apply:** When changing student access, exam loading or submission, or lesson-lock behavior, keep Promo Code access and quiz completion independent.
